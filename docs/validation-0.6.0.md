# Sound Shift 0.6.0 — проверка выпуска

## Изменения

- Приложение, системные подписи, уведомления, диагностика и установщики переименованы в **Sound Shift**. Версия обеих платформ: **0.6.0**, build/versionCode **9**.
- Mac запускается как приложение строки меню (`LSUIElement`, accessory). Значка в Dock нет. Закрытие окна и ⌘W скрывают окно, сохраняя процесс и соединение. «Открыть Sound Shift» возвращает окно; «Завершить Sound Shift» останавливает связь и приложение.
- Android один раз объясняет работу в фоне при первом запуске подключения. «Позже» не мешает подключению. Только явное «Разрешить» открывает системный запрос исключения из оптимизации батареи.
- Раздел **Настройки → Работа в фоне** показывает состояние из PowerManager и позволяет повторить запрос. После возврата из системных настроек состояние обновляется. Если основной системный экран недоступен, используются запасные экраны настроек.
- Русские и английские тексты объясняют расход батареи и дополнительные ограничения производителя. Исключение из оптимизации не означает защиту от принудительной остановки.

Battery instrumentation меняет реальное системное состояние exemption на тестовом эмуляторе и проверяет интерфейс после возврата. Запуск системного intent проверяется с подменой результата отмены; это не выдача разрешения на телефоне пользователя. Тесты восстанавливают состояние exemption и сохранённый ключ.

Воспроизводимые команды:

```sh
bash scripts/test-macos.sh
# Нужен активный macOS desktop; запускает безопасный demo mode:
bash scripts/test-macos-menubar.sh
bash scripts/build-macos.sh --dmg
bash scripts/build-android.sh
cd android
./gradlew connectedDebugAndroidTest
```

Артефакты: `SoundShift-0.6.0-android.apk`, `SoundShift-0.6.0-mac.dmg`, `SHA256SUMS-0.6.0.txt`. SHA-256 в файле используют имена без префикса каталога; проверяйте их из папки с установщиками.

## Совместимость обновления

Сохранены `app.systemresponse`, `app.systemresponse.mac`, идентификаторы Keychain/Keystore и preferences, BLE UUID, wire format и QR-маркер `seamless-headphones`. Старое значение QR является идентификатором протокола и намеренно не переименовано. Имя BLE-рекламы изменено; поиск Android использует UUID сервиса.

На Mac сначала завершите старую копию через её меню, перенесите **Sound Shift.app** в Applications и затем удалите старую копию приложения, чтобы случайно не запустить два координатора. Не удаляйте настройки или Keychain. Из-за ad hoc подписи macOS может повторно запросить доступ к ключу. На Android устанавливайте APK поверх прежней версии.

## Границы проверки

Аппаратное BLE/A2DP-переключение, длительное ожидание с выключенным экраном и конкретные ограничения Samsung/Xiaomi/других прошивок этим прогоном не подтверждены. Проверьте на своих устройствах связь при закрытом окне Mac, работу Android после выключения экрана и ручную передачу в обе стороны.

Android исключает приложение лишь из части Doze/App Standby ограничений. На некоторых телефонах дополнительно нужны «Без ограничений» и разрешение автозапуска в системных настройках приложения. Основание: [официальное руководство Android](https://developer.android.com/training/monitoring-device-state/doze-standby) и [ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS](https://developer.android.com/reference/android/provider/Settings#ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS).

Установщики сохраняют прежнюю модель подписи: Android debug, Mac ad hoc без notarization. Существующая папка `research/` не включена в публикацию.
