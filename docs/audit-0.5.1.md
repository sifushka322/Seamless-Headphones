# Аудит и исправления 0.5.1

Проверены оба нативных клиента, локальные сервисы, BLE-протокол, защита переключения, хранение ключей, интерфейсы, локализация и сборка. Серверной части у приложения нет: Mac координирует передачу, Android выполняет команды через foreground service.

## Проверка

- Swift: 177 успешных проверок — 28 протокола, 34 автоматизации, 3 транспорта/QR, 78 передачи, 13 UX-политики, 21 локализации.
- Полная компиляция macOS с SDK 26.5; CoreAudio smoke: три успешных наблюдения с известным состоянием микрофона.
- Визуально проверены четыре страницы macOS на английском в обычном и компактном окне — восемь превью.
- Android: 36 unit-тестов и 11 UI-тестов на Android 15 / API 35 — без ошибок, падений и пропусков. Проверены темы/языки, навигация, QR, недоступные команды, некорректный ввод ключа, сохранение в Keystore, очистка поля и восстановление прокрутки.
- На эмуляторе дополнительно проверены навигация, подключение и ввод ключа при масштабе шрифта 150%; поле остаётся доступным над клавиатурой, IME Done запускает валидацию.
- UI-тест смены темы выявил гонку анимации прокрутки после повторного нажатия вкладки. Исправлена причина, полный итоговый прогон прошёл.
- Android lint: 0 ошибок, 43 предупреждения. Они относятся к обновлениям зависимостей, KTX/ресурсам, программной локализации и существующему scanner orientation; обновление библиотек и замена системы локализации не выполнялись.
- Валидатор переводов: 278 общих, 155 macOS и 179 Android записей; дубликаты и параметры шаблонов проверены.
- Успешно собраны APK и DMG 0.5.1 (build 8). Проверены подписи APK/macOS-приложения и целостность DMG, сохранены SHA-256 в `dist/SHA256SUMS-0.5.1.txt`.
- `git diff --check` и синтаксическая проверка shell-скриптов прошли.

## Совместимость

Минимальная поддерживаемая версия macOS повышена с 14.0 до 14.2: защита разговора использует наблюдение за аудиопроцессами и всеми микрофонами. При недоступном состоянии переключение блокируется. Проверка только системного микрофона по умолчанию не исключала разговор через другой вход. Android по-прежнему требует API 31 (Android 12). Нижняя граница выбрана с учётом [официального примера CoreAudio process taps от Apple](https://developer.apple.com/documentation/coreaudio/capturing-system-audio-with-core-audio-taps); сами селекторы наблюдения не имеют точной availability-аннотации. macOS 14.0–14.1 отдельно не тестировались.

## Границы проверки

Эмулятор и модульные тесты не подтверждают реальную слышимость музыки, аппаратные тайминги BLE, A2DP конкретной прошивки и переключение во время настоящего звонка. Для аппаратной приёмки нужно выполнить сценарии из [scenarios.md](scenarios.md) на Mac, Android и наушниках. Необходимы ручная передача в обе стороны, потеря связи, отзыв разрешений, звонок, сон/пробуждение и новый Play после паузы.

Установщики сохраняют прежнюю модель подписи: Mac ad hoc без notarization, Android debug. Аудит не является внешней сертификацией безопасности. Существующие файлы `research/` не изменялись.
